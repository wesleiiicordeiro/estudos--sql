# Estudos de SQL

Repositório criado para registrar meus estudos e práticas de SQL durante minha formação na área de Banco de Dados.

## 🗄️ Tecnologias utilizadas

- PostgreSQL
- pgAdmin
- VS Code
- Git e GitHub

## 📚 Conteúdos praticados

Neste repositório estou praticando conceitos como:

- SELECT
- WHERE
- COUNT
- SUM
- GROUP BY
- ORDER BY
- HAVING
- INNER JOIN
- LEFT JOIN
- Relacionamento entre tabelas

## 🏢 Banco de dados utilizado nos exercícios

Os exercícios utilizam um banco de dados de exemplo com tabelas relacionadas a:

- Clientes
- Pedidos
- Produtos
- Categorias
- Itens dos pedidos

### Principais relacionamentos

- `cliente` → `pedido`
- `pedido` → `pedido_item`
- `produto` → `pedido_item`
- `categoria` → `produto`

## 📝 Exercícios

O arquivo `exercicios.sql` contém atividades práticas envolvendo consultas e análise de dados utilizando diferentes comandos SQL.

Este repositório será atualizado conforme avanço nos estudos.
